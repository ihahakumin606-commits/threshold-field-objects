# THRESHOLD FIELD

DEFINE THE IN-BETWEEN.

A standalone, English-language website for the THRESHOLD series of spatial objects: T01 Threshold Marker, T02 Wall Edge, T03 Garden Beacon, T04 Threshold Bench, T05 Canopy Frame and T06 Wayfinding Totem.

Live website: https://threshold-field-objects.ihahakumin606.chatgpt.site/

## Standalone project

This project is independent of LUMA FIELD EDITIONS. All required website files are included at the repository root. It does not require GPT, a GitHub account, an API key, external fonts or a build step to browse.

The opening retains one matched scene while scrolling, gradually resolving blur and grain as the camera moves toward the object. Product views, detail and exploded plates follow in a restrained archive layout.

## Files

- `index.html`: page structure and English content.
- `styles.css`: responsive layout and visual treatments.
- `script.js`: opening motion, collection filters and product dialogs.
- `favicon.svg`: browser icon.
- `assets/`: 11 required product and scene images.
- `.nojekyll`: serves this plain static website without Jekyll processing.

## Local preview

Serve this folder with any static HTTP server and open its local address. There are no package dependencies to install.

## Hosting

The existing public website is hosted independently of GitHub and does not change when this source project moves between repositories.

For GitHub Pages, enable publishing from `main` and `/(root)` in the new repository's Pages settings. All website asset paths are relative and support project-site subpaths. Repository creation alone does not activate GitHub Pages.

## Scope

The project list is stored locally in the visitor's browser. This concept website does not include payment processing, order submission or a production enquiry service.
